## エンジンの既知の制約

| ID   | 内容                                                                                                                                                                                                   |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| E-01 | 抜群を取れない相手の判定はタイプ相性のみ（相手の特性による無効は使用率データの型が無いと分からない）。自分側は特性・メガ後の特性（例：フェアリースキン）を考慮                                         |
| E-02 | 天気の衝突は「同じチームにある」ことだけを判定。同時に選出しなければ問題ない場合もある                                                                                                                 |
| E-03 | すばやさの基準は「参加可能な全ポケモンの最速値」。使用率データがあれば上位N体の実際の型に置き換える                                                                                                    |
| E-05 | シミュレーションの行動はヒューリスティック（確率的）。両者が同じ方針で動いた場合の推定であり、上級者の読みは反映していない                                                                             |
| E-06 | Champions の細かい仕様（まひ1/8、ねむり2〜3ターン、こおり最大3ターン等）は Showdown の champions mod に依拠（二次情報）。実数値は実機と一致を確認済み。M-C 形式は Showdown 未収録のため M-B 形式で代用 |
| E-04 | 分類データ（`packages/data/engine/tags.json`）は本編の効果に基づく。Champions での変更は未確認                                                                                                         |
