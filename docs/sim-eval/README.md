# 方針の検証の記録

方針（`packages/sim/src/policy.ts`）を変えるたびに、ここにある基準値と比べ、悪化した変更は取り込まない（ADR-0011）。

## 物差し

1. **実戦の記録**（`records/`、`pnpm sim:eval`）: いちばん信頼できる。記録がまだ無いので未計測。
2. **探索との一致**（`pnpm sim:teacher eval docs/sim-eval/teacher-positions.json --baseline docs/sim-eval/baseline-teacher.json`）:
   `teacher-positions.json` は、方針同士の対戦の各ターンで、両者それぞれの候補を何十戦ずつ試して勝率最大の行動（先生役）を付けた局面集（178局面、2026-11-28、変更前の方針で作成。以後は作り直さない）。
   - 1位一致・上位3・平均対数確率: 方針の確率と先生役の選択の比較。
   - 方針の期待勝率（`meanPolicyRate`）: 方針の確率で各候補の勝率（先生役の推定値）を平均したもの。**主な指標**。
   - 失う勝率（`meanRegret`）= 最善手の勝率 − 方針の期待勝率。最善手の勝率は推定のばらつきで高めに出るので、絶対値より前後の差を見る。
   - 制約: 先生役の探索も2手目以降は（変更前の）方針で打っている。強い人間の手と同じではない。
   - 偏り: 決勝に残った候補の勝率が同じとき、探索は旧方針の点数が高い方を選ぶ。1位一致は旧方針に有利に出やすい（期待勝率はこの影響が小さい）。
3. **倒れた後などの交代**（`pnpm sim:teacher eval docs/sim-eval/teacher-switches.json`）: 方針同士の80戦で、交代の指示が来るたびに出せる組み合わせすべてを各80戦ずつ試した局面集（127局面、`--kinds switch`）。方針の選択は決定的なので、一致率と「方針が選んだ交代の勝率」を見る。

## 変更ごとの前後比較

試すときは `pnpm sim:teacher eval docs/sim-eval/teacher-positions.json --baseline docs/sim-eval/baseline-teacher.json --set 係数=値`。
採用の基準: 全局面と、局面を偶数番目・奇数番目に分けた両方（`--half even|odd`）で、どの指標も悪化しないこと（件数が少ないので、片方だけの改善は採用しない）。期待勝率は ±0.1 ポイント以内なら同じとみなす（推定のばらつきより十分小さい）。

読み取れること:

- 探索は「片方で倒せそうな相手にも2匹で攻撃する」を選ぶことが多い。見積もりは平均値で、外れ・守る・交代・乱数で倒し損ねるため、重ねた攻撃は保険として価値がある。合算して上限を付ける（R-2 の中心）と探索から大きく離れる。
- 上から倒される側の守る・交代を増やす（R-1）は「守る」の一致を上げるが、ねこだまし・攻撃の一致を下げる。弱い交代の加点だけが一貫して良い。
- 期待勝率の差はどれも ±0.5 ポイント以内で、この局面数では区別できない。実戦の記録がそろったら、同じ係数を `sim:eval` で測り直す。
