## ゲームデータ

| データ                                  | 出典                                    | 扱い                                                          |
| --------------------------------------- | --------------------------------------- | ------------------------------------------------------------- |
| 種族値・タイプ・技の基本データ          | `@smogon/calc`（Pokémon Showdown 由来） | 事実情報として利用。Champions差分は `overrides.json` で上書き |
| SP 上限・計算式                         | 攻略サイトの二次情報（Web検索の要約）   | `verified:false`。OPEN_QUESTIONS Q-01/Q-02                    |
| レギュレーション `M-B` の使用可能リスト | 仮のサンプル（出典なし）                | `verified:false`。OPEN_QUESTIONS Q-04                         |
| 日本語名                                | 手入力（少数）                          | `verified:false`。OPEN_QUESTIONS D-04                         |

公式のスプライト・画像・ロゴ・BGM・フォント。UIのアイコンはすべて自作またはライセンスの明確な汎用アイコンを使う。
