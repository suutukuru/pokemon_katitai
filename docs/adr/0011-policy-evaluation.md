# ADR-0011: 行動方針を実戦の記録で検証する（sim:eval）

- 状態: 採用
- 日付: 2026-11-28

## 背景

選出の勝率表・1ターン目の択・最善手の探索は、すべて先の展開を `policy.ts` の簡易方針に打たせている。方針を直す（素早さ順、2匹の連携、相手の守る、交代…）たびに「実戦に近づいたか」を数字で判断したい。

## 決定

- 実戦の記録の形式を `@ca/schema` の `BattleRecordSchema` に定義する。入手は手入力か、ユーザーが保存した Showdown のリプレイログ（`@ca/ingest` の `parseShowdownReplayLog` で変換）だけ。自動収集はしない（D-02）。
- 評価（`packages/sim/src/eval.ts`）は記録を Showdown 上で再現しながら、各ターンの開始時に記録の HP・状態異常・能力変化を書き込み、その局面で方針が出す確率と実際の行動を比べる。乱数の違いで次のターンの場が記録と食い違うときは、同じ局面からサイコロを振り直す（`weights.simulation.evalReplayRetries`）。それでも合わなければその記録はそこで打ち切り、理由を出力する。
- 方針の確率は `policyDistribution()`（2匹の行動の組み合わせごとの確率）から取る。方針を組み合わせ単位にしても（R-2）評価側は変えずに済む。温度は `weights.simulation.temperature`（相手の行動の模型として使っている値）。
- 指標: 1位一致率、上位3以内の割合、実際の行動の確率の対数の平均。1匹ごとと2匹まとめて、実際の行動の種類（守る／ねこだまし／交代／素早さ操作／攻撃／その他、2匹まとめての集中攻撃）ごと。選出は予備戦の勝率順で実際の4匹・4匹＋先発・先発が何位か（6匹ずつ分かるとき）。
- `pnpm sim:eval <記録 | ディレクトリ> [--json] [--baseline 前回.json]`。方針の各修正は基準値との比較を残し、悪化したものは取り込まない。

- 実戦の記録が無い間は、探索（`bestplay.ts` の逐次半減）を先生役にした局面集（`docs/sim-eval/teacher-positions.json`、`pnpm sim:teacher build`）で代わりに測る。局面は「シード＋全 choose の履歴」で保存し、方針が変わっても同じ局面を再現できる。ラベル（先生役の選択と各候補の推定勝率）は作成時点で固定。主な指標は方針の期待勝率（候補の推定勝率を方針の確率で平均）。

## 影響・制約

- 再現は近似（E-08）。天気・フィールド・壁などは同期しない。
- 手入力の記録はメガシンカを書かない限り「しない」扱い。行動の照合ではメガの有無は見ない。
