# ADR-0010: 相手の技構成は Smogon の使用率統計（Showdown の Reg M-C）から推定する

- 状態: 採用
- 日付: 2026-11-21

## 背景

上位構築の公開データ（pokedb）は「ポケモン・持ち物」だけで技が無い。ユーザーが記事から技を書き写すのは負担が大きい。
pokedb の使用率ページは利用規約第3条（競合サービス関係者によるデータ取得の禁止）のリスクがあるため使わない（ADR-0008）。

## 決定

- Smogon が毎月公開している Pokémon Showdown の使用率統計（https://www.smogon.com/stats/ 、chaos JSON）を使う。
  Showdown には「[Gen 9 Champions] VGC 2026 Reg M-C」があり、2026-10 はレート1760以上で約165万戦。技・持ち物・特性・SP配分・同時採用の分布がある。
  robots.txt は一般の取得を制限していない。月1回、必要なファイル（Reg M-C の 1760 / 1500）だけを手動で一度取得し、
  `pnpm data:import-smogon` で上位分布だけに縮めて `packages/data/usage/<レギュレーション>/` にコミットする。実行時には取得しない。
- 相手の構築の補完（`estimateTeam`）: ポケモンと持ち物は pokedb 公開データ（実際の値）、技・特性・性格・SP は使用率の最多の型。
  こだわり系の持ち物なら変化技を除く。補完した項目は `assumed` に入れ、出力には「推定」と明記する。
- 診断の「使用率上位N体」ルールもこのスナップショットを使う（Web も同梱、必要時に読み込み）。
- Showdown のラダーは実機のランクマッチとは別の母集団。メガ枠など一部の傾向が違う可能性がある（OPEN_QUESTIONS E-07）。

## 影響

- 商用化時は Smogon の統計の利用条件を確認する（OPEN_QUESTIONS L-08）。
