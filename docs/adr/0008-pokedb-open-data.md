# ADR-0008: 上位構築データは pokedb の「公開データ」だけを使う

- 状態: 採用
- 日付: 2026-11-21

## 背景

ユーザーは バトルデータベース チャンピオンズ（champs.pokedb.tokyo）の使用率ページ・構築記事検索を参照している。
同サイトの利用規約（2026-06-11 改定）第3条は「競合するサービスの運営・開発に関与する者によるデータ取得」と
「大量のデータ取得を目的とした継続的・断続的アクセス」を禁止している。一方で「上位構築データの公開について」
（/guide/opendata）では、順位・レート・ポケモン・持ち物を CSV/JSON で公開し、プログラムでの取得（過度な負荷なし）と、
アプリでの利用（自前で一度保存して使い、エンドユーザー端末から直接リクエストしない）を明示的に認めている。

## 決定

- 使うのは公開データ（`/opendata/s{n}_{single|double}_ranked_teams.json`）だけ。1シーズン1ファイルを手動で一度だけ取得し、
  `pnpm data:import-pokedb <dir>` で正規化して `packages/data/teams/pokedb/` にコミットする。アプリ・CLI は実行時にアクセスしない。
- 使用率ページ（技の採用率など）、ポケモン詳細ページ、構築記事ページは**自動取得しない**（規約第3条のリスク）。
- 公開データには技・SP・特性・性格が無い。`published` フラグで明示し、エンジンは推測で埋めない。
- 持ち物の日本語名のうち PokeAPI に無いメガストーンは、公開データの持ち主から一意に決まる場合だけ `names.extra.json` に追加（出典付き）。

## 未決

- 有料化する場合、本アプリが規約上の「競合サービス」に当たるかは運営者（X: @pokedb_tokyo）への確認が必要（OPEN_QUESTIONS L-07）。
- 技構成（対策プランの探索に必須）の入手経路（OPEN_QUESTIONS D-06）。
