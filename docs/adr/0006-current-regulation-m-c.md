# ADR-0006: 仮パック M-B を削除し、公式データから M-C を作る

- 状態: 採用
- 日付: 2026-11-21

## 背景

フェーズ1では、レギュレーション名の確証が無いまま `M-B` を仮パックとして作り、使用可能リストも手で選んだサンプルだった。
その後、ユーザーから「現行は M-C」との情報と、公式サイトの「参加できるポケモン」ページの URL を得た。

## 決定

- `M-B` は実在のレギュレーションの記録ではなく、実データに基づかないサンプルだったため削除する（「過去のパックは消さない」原則は、実在したレギュレーションの記録に適用する）。
- `M-C` をルートパックとして新規作成。使用可能ポケモンは公式ページの262件（ギルガルドは newSpecies で補完）。
- 公式ページはシングル（シーズンM‐6）のもの。ダブルでも同じかは未確認のため、`legal.provenance` に出典と注記を残す。
- `legal.json` に `provenance`（リストごとの verified / 出典 / 注記）を追加。種族は公式、持ち物とメガ対象は仮、のように**リスト単位で確度を区別**できるようにした。
- ダミーの次パック `X-NEXT-DUMMY` は `M-C` を継承するよう変更。
