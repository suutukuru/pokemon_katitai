# ADR-0011: 行動方針を「2体まとめて・相手の行動を予測して」決める（policy 2）

- 状態: 採用
- 日付: 2026-11-21

## 背景

ADR-0009 の行動方針（policy 1）は、場の2体それぞれの技を**別々に**点数付けしていた。対戦ログを見ると次のような非現実的な動きが多かった。

- 2体が同じ相手を狙って過剰に攻撃する（片方で倒せるのに両方で殴る）。
- 素早さ・優先度を見ていない（先に倒されて動けない技、倒して攻撃を止められる価値を区別しない）。
- 相手の行動を予測しない（まもる・交代の価値が「自分が倒されそうか」の粗い目安だけ）。
- 瀕死後の交代は「控えの先頭」を出すだけ。
- 相手の温度（ランダムさ）が 0.35 と高く、相手が弱いAIとして動くため勝率が楽観的になる。

## 決定

`packages/sim/src/planner.ts` に2体同時の行動計画（policy 2）を実装し、`weights.json` の `simulation.policy = 2` で有効にする（1 で旧方針）。

- 相手の各ポケモンの攻撃を、同じダメージ見積もりのソフトマックスで予測する（`foeModelTemperature`）。まもるの確率は危険度から（`foeProtect*`）。
- 行動順は Showdown 自身の `getActionSpeed()`（おいかぜ・トリックルーム・スカーフ・まひ・すいすい等を含む）と技の優先度（いたずらごころ・グラスフィールドのグラススライダー等）。
- 2体の行動の組をまとめて評価する: 同じ相手へのダメージは合計してHPで頭打ち、先に倒されて動けない確率・ねこだましで怯む確率で割り引き、相手が動く前に倒せた場合は相手の攻撃を止めた価値（`denialWeight`）を加える。
- まもる・交代は「避けられる被ダメージ」で評価（交代先が受けるダメージを差し引く）。ねこだましは怯ませる相手の脅威度、おいかぜ・トリックルームは素早さの上下が入れ替わる組の数で評価。
- 瀕死後の交代は、場の相手に対する攻撃力と被ダメージで控えを選ぶ。
- ダメージ見積もりに主な特性・持ち物・フィールド・壁・威力が変わる技を追加（判定用ではなく順位付け用。実際の結果は Showdown が出す）。
- 自分と相手の温度を同じ（0.05）にした。相手は自分と同じ強さで動くと仮定する。
- 選出の予備戦を2段階にした: 全90通り×16戦（相手の選出は一様）→ 上位20どうしで各40戦（`screenKeep` / `screenBattles2`）。読み合いの表は上位8×8。
- `pnpm sim:bench` で方針どうしの強さを測る（同じ選出・乱数で陣営を入れ替えて2回ずつ）。

## 検証

- policy 2 対 policy 1: 自分の構築3つと相手サンプル2つの総当たりで 69%（1000戦）、`team2` 対 pokedb M-7 4位で 65%（80戦）。
- 重みの調整は自己対戦で行った（各800〜1000戦）。温度 0.05・`protectCost` 0.3・`tailwindValue` 1.0 の組み合わせが基準より 55%（2000戦）。他の候補は誤差の範囲だった。
- 1戦あたりの計算は約1.6倍（約35ms）。`pnpm sim` 1回は4コアで約2分（約10,600戦）。

## 影響・今後

- 結果はあくまで「この方針同士なら」の推定（推測を含む）。ヒューリスティックの強さには上限があり、重みの調整だけでは伸びにくい段階に来ている。
- 次の改善候補: (a) 各ターン上位数手だけ Showdown で1手先を読む、(b) 交換・テラス等の読み合いをさらに明示的に、(c) 対戦ログからの重み学習。
