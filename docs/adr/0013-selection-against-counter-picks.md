# ADR-0013: 選出は相手のカウンター選出まで含めて検証する

- 状態: 採用
- 日付: 2026-11-26

## 背景

`analyzeMatchup` は両者の選出を予備戦で上位 `topConfigs` 通りに絞ってから読み合いを解く。相手の上位がすべて同じポケモン（例: ペリッパー）を含むと、
「相手は必ずペリッパーを出す」前提の推奨になる。実際には相手はこちらの6体を見て選出するため、その前提を外した選出（カウンター）で崩れる。
ユーザーの指摘（雨の相手にブリジュラス先発で相手の雨を借りる選出は安定しない）で判明した。

## 決定

- `analyzeSelectionRobust`（packages/sim/src/robust.ts）: 自分の選出は上位 `myTop` 通りに絞るが、**相手は全選出（4/6で90通り）を残す**。
  自分の上位×相手の全選出を方針どうしで総当たり → ゼロサムゲームとして解く → 均衡で相手が使う選出と、自分の各候補に一番効く相手の選出（カウンター）を、
  両者が探索する対戦で再対戦して解き直す。最悪の相手選出での勝率（maximin）も出す。
- `pnpm sim:select` がこれを実行し、相手の各ポケモンを選出・先発させる確率と、相手が各ポケモンを出す／出さないときの勝率をページにする。

## 結果（chomp-hawk-psy vs ワイドガード雨、10072戦）

- 推奨: ガブリアス・ムクホーク ／ 後ろ グレンアルマ・ブリジュラス（71%、最悪でも68%）。相手がペリッパーを出しても出さなくても勝率はほぼ同じ。
- 以前の推奨に近い「ガブリアス・ブリジュラス先発」は、相手がペリッパー抜きで先発する（ブリジュラス・イダイトウ先発）と33%まで落ちる。

## 今後

- 相手の候補は「全選出」だが評価は方針どうしの対戦が中心。探索で確かめるのは均衡の支持とカウンターだけ。
- `report:teambook` / `web:data` の選出も、この検証に置き換えるか併記する。
